# Support

For help with a Lithodium project, start with the project's GitHub repository.

## Where to Ask

- Use **Issues** for bugs and feature requests.
- Use **Pull Requests** for proposed code or documentation changes.
- Use existing discussions or documentation when your question has already been answered.

## Feature Requests

Feature requests are reviewed through GitHub. A request may be accepted, declined, or kept for later depending on its usefulness and fit with the project.
