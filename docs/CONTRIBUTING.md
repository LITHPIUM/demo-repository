# Contributing to Lithodium

Thanks for taking the time to contribute.

## Before You Contribute

For a feature or change, please open an Issue first when practical. This helps establish what should be changed before work begins.

For bugs, include clear reproduction steps, expected behavior, actual behavior, and relevant logs or screenshots when available.

## Pull Requests

Pull Requests should:

- Have a clear purpose.
- Keep changes focused.
- Avoid unrelated modifications.
- Include relevant documentation when behavior changes.
- Be ready for review before requesting a merge.

All contributions are reviewed through GitHub.

## Feature Requests

Feature requests belong in GitHub Issues. Requests are reviewed based on usefulness, scope, compatibility, and the direction of the project.

Not every request will be implemented, but every reasonable request can be considered.

## Code Quality

Keep code readable, maintainable, and consistent with the existing project.
