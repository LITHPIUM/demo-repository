# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose a security vulnerability before it has been reviewed.

Report security issues privately to:

**aurianhayes@gmail.com**

Include as much useful information as possible, including affected files or versions, reproduction steps, impact, and any relevant proof of concept.

## Response

Security reports will be reviewed as soon as reasonably possible. Valid issues may result in a fix, mitigation, or other appropriate response.

Please allow time for investigation before publicly discussing an unresolved vulnerability.
