# Code of Conduct

Lithodium is committed to keeping its projects open, professional, and respectful.

## Expected Behavior

- Be respectful and constructive.
- Focus criticism on code, ideas, and technical decisions rather than people.
- Keep discussions relevant to the project.
- Accept reasonable technical disagreement.
- Do not harass, threaten, or discriminate against others.

## Unacceptable Behavior

Harassment, personal attacks, discrimination, malicious disruption, spam, and other abusive behavior are not acceptable.

## Enforcement

Project maintainers may remove comments, close discussions, restrict participation, or take other reasonable action when this code of conduct is violated.
