ABOUT LITHODIUM

Software with a reason to exist.

Lithodium is an open source organization founded by Audrian Haye, focused on building reliable, useful, and thoughtfully made software projects.

What we do

We specialize in open source projects across software development. Our work is focused on performance, simplicity, reliability, and creating projects people can actually use.

How we release

When a project is released, it is treated as a finished release rather than something that needs constant updates. We look at requests, issues, and pull requests from the community and use them to decide what deserves attention.

Open by default

Our development happens in the open. Community feedback is handled through GitHub Issues and Pull Requests so requests and contributions can be reviewed clearly.
