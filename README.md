# Lithodium

Lithodium is an open source organization focused on building useful, reliable, and thoughtfully designed software.

## About

Our projects are built with purpose. We aim to release software that is simple to use, reliable, and worth keeping.

A release is not treated as unfinished simply because it is not constantly updated. We focus on meaningful improvements rather than updates for the sake of updates.

## Requests & Contributions

Have an idea, improvement, or fix?

- Open an Issue for feature requests, questions, or problems.
- Open a Pull Request when you have a change ready to contribute.
- Please provide enough detail for requests and changes to be reviewed properly.

Community feedback is reviewed through GitHub.
