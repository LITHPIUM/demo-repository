ABOUT LITHODIUM

We build software worth keeping.

Lithodium specializes in open source projects designed with a clear purpose. We care about performance, simplicity, reliability, and the people who use what we build.

Our projects aren't built simply to release another version. We take the time to build them properly and release them when they're ready.

02

OUR APPROACH

01

Build with purpose.

Every project starts with a reason. We focus on creating software that solves real problems instead of adding unnecessary complexity.

02

Release with confidence.

When a project is released, we consider that release something we're proud to stand behind. We don't update projects simply for the sake of having an update.

03

Listen to the community.

Requests, improvements, and contributions are welcome through GitHub Issues and Pull Requests. Good ideas deserve to be heard.

OUR STANDARD

We never disappoint.

We build with intention, release with confidence, and stand behind our work.
