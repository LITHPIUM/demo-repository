# Governance

Lithodium projects are maintained with a focus on quality, usefulness, and long-term stability.

## Maintainers

Maintainers are responsible for reviewing contributions, managing releases, addressing important issues, and keeping the project aligned with its goals.

## Decisions

Technical decisions are evaluated based on correctness, maintainability, performance, compatibility, and project scope.

## Community Input

Community feedback is welcome through GitHub Issues and Pull Requests. Requests are considered carefully, but submitting a request does not guarantee implementation.

## Releases

Projects are released when they meet their intended goals. Lithodium does not make unnecessary updates solely to increase release frequency.
